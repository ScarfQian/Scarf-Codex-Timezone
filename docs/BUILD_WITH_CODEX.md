# 给另一台电脑上 Codex 的配置与构建任务

日期：2026-10-15  
创建人：ScarfQian

请阅读本仓库源码和 README，在我的电脑上配置 Scarf-Codex-Timezone。目标是让 Codex 桌面应用采用其实际 GPT 网络出口的时区，保留系统时区，并提供真实核验和恢复入口。

## 先确认本机环境

1. 检查是否为 macOS，找到 Python 3.9+、curl 和实际 Codex 可执行文件，不照抄其他电脑的应用路径。
2. 只读确认模型服务地址，是否经过本地或远程网关，以及最终模型请求由哪个进程、哪个域名发起。
3. 读取 Clash/Mihomo 的有效运行配置，识别 HTTP/mixed 代理端口、可访问的本机 Unix 控制 socket、GPT 策略组及展开后的节点。
4. 核对活动模型连接的规则和代理链。模型 API 网关端口不是 HTTP 正向代理端口，不能互换。

不要读取账号或订阅凭据，也不要为满足本工具默认检查而修改我的代理规则。复杂规则或远程网关不在当前实现支持范围时，先明确指出差异，再按真实路径适配。

## 配置并验证

将适合本机的配置保存到 `~/Library/Application Support/Scarf-Codex-Timezone/config.json`。从 `config.example.json` 出发，填写实际 `codex_group`、`proxy`；必要时填写 `codex_app`、`mihomo_socket`。允许国家是用户策略：默认美国，`["*"]` 表示允许所有有效国家，并不将所有国家映射为某个固定时区。

先运行回归检查和只检测出口：

```sh
python3 -B -m unittest -v test_timezone
python3 -B launcher.py --check-only --json
```

出口检测通过 ChatGPT 域名路径读取公网 IP，再查询这个指定 IP 的 IANA 时区。通用 IP 查询网站可能走另一条分流，不能直接替代；节点名称、国旗和订阅标签也不能用于推测时区。

如需隔离实测，使用 `timezone_probe.py` 的独立命令行参数；它不读取启动器配置。临时用户目录只用于测试，不能把空白实例当作我的实际登录实例。只清理测试自己创建的进程。

## 构建与实际登录实例验收

运行 `python3 -B build_app.py`，将生成的 `dist/Scarf-Codex-Timezone.app` 复制到我指定的位置。构建时选择的 Python 路径必须在本机持续可用；应用包本身不含 Python。

如果 Codex 正在运行，完成其他准备后提示我保存工作并按 `⌘Q` 完整退出，不要强制结束它。由我通过工具选择“按出口启动”，核对：

- 出口目标时区与所有实际 Codex 页面读到的时区一致。
- 当地日期和 UTC 偏移符合相同时间戳下的目标 IANA 时区，包括夏令时。
- macOS 系统时区没有改变。
- 新消息中确实收到的客户端 `timezone/current_date` 与目标一致。没有提供这项上下文时应报告未验证，不能根据 IP、历史聊天或终端时间猜测。

报告的 `model_context_verified: false` 是有意保留的：自动工具只读页面，没有自动检查模型请求。实际新消息的证据应单独说明。

## 恢复与使用边界

0.2.1 首次正常打开管理工具默认开启自动跟随，安装用户级后台检测并接入 Codex 的 Dock 启动入口；关闭窗口不取消。开关面板只显示开启或关闭，提供“关闭自动 / 更多操作 / 完成”；关闭后显示“开启自动”，关闭设置会一直保留到用户主动开启，升级也保留已有关闭设置。点击关闭即停止服务、恢复本工具修改的 Dock 项，保留当前 Codex 时区和其他 Dock 修改。日常启动、恢复、开关及后台检查均不弹报告或系统通知，仅主动查看状态或检测时显示报告。只检测、查看状态和 `--help` 不安装服务；需要从一开始保持关闭时，可先执行 `python3 -B launcher.py --set-mode manual --json`。

自动模式下，应用未运行时只准备目标，不自行打开 Codex。已运行实例跨时区换出口或绕过默认入口启动时，在后台记录“待同步”，主动查看状态后可按说明保存工作并完整退出重开。不要通过只覆盖页面或强退应用来冒充全应用即时同步。

完整退出 Codex 后，选择“恢复本机时区”，启动器会移除子进程环境中的 `TZ` 并核验；直接从原来的 Codex 图标打开也会恢复正常启动环境。关闭本工具、关闭提示框或只关闭 Codex 窗口，不会恢复仍在运行的进程。

不修改系统时间、系统时区、全局环境、应用安装包或已有账号配置，不改写已保存的自动化时区。运行中换节点不会自动同步；重新检查发现不一致时，完整退出后再次使用启动器。

实际页面核验通过本机随机诊断端口完成。该端口具备页面调试能力，只能绑定回环地址，不能对局域网/公网开放或做端口转发。检查只读取时区、日期和偏移，不读聊天、不发消息、不设置页面覆盖。

未验证的操作系统、应用版本、路由与接口行为应具体说明。不能把运行无报错或隔离测试成功写成我的实际登录实例已经成功。
